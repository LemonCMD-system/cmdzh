# cmdzh
## 中文版CMD，可直接用中文指令！
## Chinese version of CMD, allowing direct use of Chinese commands!
### Windows内置的CMD似乎并不错，可是他并不支持原生中文命令，因此，cmdzh出现了。
The built-in CMD in Windows seems not bad, but it doesn't support native Chinese commands. Therefore, cmdzh emerged.
### 内置CMD几乎所有命令，您可用中文完成您以前想做却因不懂英文而无法完成的事！
It comes with almost all the commands of the built-in CMD. You can now do in Chinese what you wanted to do before but couldn't do because you didn't understand English!
### 支持原版英文指令、参数，支持运行batch和cmd脚本！
Supports original English commands and parameters, and supports running batch and cmd scripts!
### 若您需要查看命令列表，您可将它下载下来运行，并输入“帮助”查看。
If you need to view the command list, you can download it and run it, then enter "帮助" to view it.
若您感觉这个项目还不错，请给作者一个"Star"，谢谢！
If you think this project is good, please give the author a "Star". Thank you!
